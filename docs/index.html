FAQ

Still stuck? Ask on Discord.

Is ArkHub safe to use?

ArkHub doesn't read or change the game's memory or files, except INI files you choose to edit, and it backs those up first. It only sends ordinary keyboard and mouse input, like you would yourself. There are no network exploits (no desync, no overcap).

Can I get banned?

Input automation such as autoclickers, macros, anti-AFK and auto-farming is against the rules on official servers and on many unofficial ones. Use those features only in single-player or on servers whose rules allow macros. The visual and setup tools (crosshair, gamma, INI, launch options, server info) are generally fine, but check your server's rules. You use ArkHub at your own risk.

Does it work with Survival Ascended?

Yes. ArkHub detects both ASE and ASA installs. For the overlays (crosshair, server info), play in Windowed or Windowed Fullscreen mode.

What do I need?

Windows 10 or 11 and an internet connection to activate. If you lose connection, ArkHub keeps working for up to 48 hours before it needs to check your key again.

I got a new PC. What now?

Join the Discord and type /reset with your key. It unlocks the key so you can activate it on the new PC (once every 7 days).

How do updates work?

ArkHub checks for updates on its own, shows you what's new and installs in one click. Your settings and macros are kept.

Windows says "unrecognized app". Is that normal?

Yes. It's normal for small indie apps without an expensive code-signing certificate. Click More info → Run anyway. Only download ArkHub from this site.
